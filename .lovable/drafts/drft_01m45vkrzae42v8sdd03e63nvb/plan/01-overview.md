# Destination gallery and itinerary editor

## What will change

- Show up to four destination photos in one compact row on every screen size.
- Keep all four visible on mobile with smaller square/landscape tiles instead of a wide page overflow.
- Put a dark `+X more` overlay on the fourth photo when additional photos exist; tapping any photo opens the existing full gallery at that photo.
- Reduce the gap below the gallery and above Sample Itineraries while preserving a balanced section break.
- Add an editable **Title** field to every existing itinerary, aligned with the existing Price and Nights / Days controls and stacked cleanly on mobile.
- Save title edits through the existing protected itinerary-management path; no upload or parsing behavior changes.

## Scope preserved

The destination hero, full gallery modal, itinerary cards, PDF parsing, photo extraction, and all other admin controls remain unchanged.
